Radian628 Wikidot Usertools

Found a bug? Open an issue or a PR here!

Here's a few tools for making Wikidot (mainly the SCP Wiki) more bearable to use.

Usage

Nearly all of these usertools require a UserScript manager to properly use (though some can just be pasted into your developer console). Here are a few UserScript managers I recommend.

  • Tampermonkey
  • Violentmonkey
  • Greasemonkey

Usertools

(REQUIRED FOR ALL TOOLS) Usertools Base

Installation Link

This is a base extension that provides common functionality used by all usertools (menus and such and such).

Standard Usertools Bundle

Installation Link

Contains the following usertools, which can all be toggled individually:

  • Better Editor - Replaces the SCP Wiki editor with a new editor that supports syntax highlighting for CSS/HTML/JS, saving without exiting the editor, CSS hot-reloading, and inline compile-time JavaScript expressions.
  • Better User:Info - Completely overhauls the layout of Wikidot user:info pages, putting all info on one screen and enabling search.
  • Copy Page Source to Clipboard Button - Adds a button, always visible on the screen, that copies the current page's Page Source to your clipboard.
  • Custom CSS Widget - Adds a window to the bottom-right of the page, which allows you to inject CSS into the page.
  • Minimalist Editor - Replaces the Wikidot editor with an editor that shows the text you're typing, and NOTHING else, for a distraction-free experience. Auto-saves every 60 seconds, or whenever you hit Ctrl-S.
  • Multisave - Upload, save, rename, and delete multiple files on your pages at once.
  • Smart History - Replaces the Page History UI to make it nicer to look at and easier to use.
  • Unfuck All CSS - Sometimes, these userscripts can inexplicably cause Wikidot's CSS to break. If this occurs, just enable this tool to fix it.

SCP Usertools Bundle

Installation Link

Contains everything in Standard Usertools Bundle, plus the following SCP-specific tools:

  • AutoLocalize - Automatically reupload images from other sites onto the SCP Wiki.
  • SCP Sandbox Mirrorer - Replicates the exact HTML layout of scp-wiki.wikidot.com onto scp-sandbox-3.wikidot.com to help with testing site themes.
